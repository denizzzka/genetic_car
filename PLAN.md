# PLAN

## Steps

- [ ] Сохранение генома
  - [ ] Версионированный формат: сигнатура, версия, набор генов вида и фаз.
  - [ ] При загрузке проверять версию, конечность значений и границы `speciesLo`/`speciesHi`, `segmentLo`/`segmentHi`; при несовместимости - явная ошибка, а не молчаливый мусор.
  - [ ] Начальные параметры (значения по умолчанию, основатель) тоже валидировать при загрузке.

- [ ] Сохранение каркаса в структуре сохранения
  - [x] Решено: каркас храним всегда, это обязательная часть формата, а не fallback.
  - [ ] Узлы, балки (радиус, kind), якоря (node, kind, radius), motorPower.
  - [ ] При загрузке использовать сохранённый каркас, а не вызывать `develop`.
  - [ ] Версия/хеш каркаса и кабины, `validateFrame`; при несовместимости - явная ошибка.
  - [ ] Дополнительная проверка по флагу: вырастить каркас из сохранённого генома заново и сравнить с сохранённым; расхождение - предупреждение, а в строгом режиме ошибка, что грамматика/код изменились.
  - [ ] При расхождении показывать, что именно не совпало: число узлов, балок, якорей и координаты с допуском; хеш считать по квантованным значениям, чтобы не ловить шум libm.
  - [ ] Геном хранить рядом: он нужен для разведения и переращивания по новым правилам.

- [ ] Сохранение состояния физического мира в объект
  - [x] Позы и скорости мастера, руля и колёс; балки и кабина выводятся из них.
  - [x] Шарниры и цель руля; Box3D дополнительно отдаёт контакты с warm start.
  - [ ] Окружение: маршрут и его генератор; конфиг рельефа и окно тайлов нужны для файла.
  - [x] Состояние заезда: газ, руль, таймеры застоя/схода, время; контакты пересчитываются.

- [ ] Восстановление физического мира
  - [x] Box3D: мир восстанавливается целиком, включая контакты, острова и рельеф.
  - [x] Проверить детерминизм: после отката Box3D шаги совпадают бит-в-бит (тест).
  - [ ] Jolt: `SaveState`/`RestoreState` есть в C++, но не в C-API dagon; нужен патч обёртки или снимок тел.
  - [ ] Newton: сериализация сцены колбэками, но warm start не гарантирован.

- [ ] Сохранять состояния раз в 5 секунд на 30 секунд
  - [x] Кольцевой буфер 5/30: 7 слотов, старые снимки выпадают по времени.
  - [ ] Подключить буфер к живым заездам и чистить его на сходе/финише.
  - [x] Память ограничена слотами; снимок освобождается при перезаписи и `clear`.

- [ ] Откатывать и пробовать проехать по-другому при неудаче
  - [x] Примитив отката к новейшему снимку или к снимку не позже времени.
  - [ ] На сходе восстанавливать снимок на 5 секунд назад.
  - [ ] Пробовать варианты газа: сбросить, держать, поддать.
  - [ ] Обсудить стратегию: сколько попыток, какие снимки, как выбирать лучший вариант, как не зациклиться на одном месте.

- [ ] Стремиться держать окружную скорость колеса 75 км/ч на длительном периоде
  - [ ] 75 км/ч = 20.83 м/с; считать по генетическому радиусу каждого колеса.
  - [ ] Верхний предел убрать: `wheelMaxSurfaceSpeed`/`wheelOmegaMax` не ограничивают скорость; 75 км/ч - только цель.

- [ ] Постепенно вводить всё более высокие горы
  - [ ] Отдельный крупномасштабный слой высот поверх текущего FBM: гребни и склоны, а не только мелкая рябь.
  - [ ] Амплитуду наращивать с дистанцией от старта через тот же ramp, без ступенек: сначала пологие холмы, дальше всё выше.
  - [ ] Склоны длиной примерно 2-3 тайла (16-24 м при tileSize = 8 м): задавать радиусом горы или длиной волны гребня, а не амплитудой напрямую.
  - [ ] Следить, чтобы рост высоты не превращал склон в стену: ограничить перепад на ячейку heightfield и проверить, что машина реально заезжает.
  - [ ] Тесты: детерминизм, бесшовность тайлов, профиль вдоль маршрута, максимальный уклон.

- [ ] Загрузка и выгрузка багги и состояний мира в файлы
  - [ ] Отдельные файлы: геном и каркас, снимки мира, метаданные версии.
  - [ ] Box3D-снимок ссылается на store геометрии: для файла хранить каркас и тела или сериализовать store.
  - [ ] Единый формат для CLI и вьюера; понятные ошибки при несовпадении версий.
