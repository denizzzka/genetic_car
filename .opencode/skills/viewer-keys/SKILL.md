# Viewer Keys

## Когда применять

Баг вьюера `genetic_car` воспроизводится только после нажатий клавиш (например,
пуск эволюции на G или живой заезд на V). Скилл даёт утилиту, которая шлёт
клавиши в уже запущенное окно, и рецепт запуска вьюера так, чтобы stdout был
доступен агенту.

## Требования

- Графическая сессия X11 (в этой системе `DISPLAY=:0`, XTEST доступен).
- `python3` с модулем `python-xlib`. Проверка:

  ```sh
  python3 -c "import Xlib; print('ok')"
  ```

## Запуск вьюера

Скилл сам приложение не запускает и не закрывает — это делает агент. Запускай
вьюер в фоне с редиректом в файл, иначе его stdout (строки поколений, события
живого заезда) потеряется:

```sh
cd /home/denizzz/Dev/genetic_car && dub run -- --engine jolt > /tmp/genetic_car.log 2>&1 &
```

`dub run` сам выставляет `LD_LIBRARY_PATH` (см. `dub.sdl`). Движок по умолчанию —
`jolt`; альтернатива — `--engine newton`. Сборка и старт небыстрые (считается
нулевая популяция), поэтому следующему шагу нужен `--wait`.

## Нажатия

Утилита лежит рядом со скиллом: `scripts/press_keys.py`. Путь указывай
относительно каталога скилла.

Одно нажатие (например, пуск эволюции):

```sh
scripts/press_keys.py --wait 120 --keys G
```

Несколько клавиш подряд с паузой `--delay` между ними:

```sh
scripts/press_keys.py --keys G,V
```

Паузы длиннее секунды утилита не делает: между вызовами спи сам, обычным `sleep`:

```sh
scripts/press_keys.py --keys G
sleep 10
scripts/press_keys.py --keys V
```

Полезное для диагностики:

```sh
scripts/press_keys.py --list-windows      # какие окна видит утилита
scripts/press_keys.py --pid 12345 --keys G  # адресовать окно по PID процесса
```

По умолчанию клавиши уходят через `XSendEvent` прямо в окно, фокус не
перехватывается. Если окно не нашлось, утилита печатает, что искала и что есть.

## Чтение результата

G печатает строки поколений, живой заезд — строки `live:`:

```sh
grep 'gen ' /tmp/genetic_car.log
tail -n 20 /tmp/genetic_car.log
```

## Если события не доходят

SDL-приложение может игнорировать синтетические `XSendEvent` (XInput2). Тогда
повтори с `--focus`: утилита на миг забирает фокус через XTEST и возвращает его
прежнему окну.

```sh
scripts/press_keys.py --focus --keys G
```

## Остановка вьюера

```sh
pkill -f genetic_car
```

## Карта клавиш

| Клавиша | Действие | Где |
|---|---|---|
| G | пуск/останов эволюции (тогл) | `source/viewer/viewer.d` |
| V | показать/спрятать живой заезд | `source/viewer/viewer.d` |
| R | новое 0-е поколение (вне фоновой эволюции) | `source/viewer/viewer.d` |
| D | дебаг-скелет эфемерных балок | `source/viewer/viewer.d` |
| N | следующая особь в живом заезде | `source/viewer/viewer.d` |

## Тонкости

- G, V, D, R — тоглы: лишнее нажатие инвертирует состояние. Нажимай один раз и
  сверяйся с логом.
- N срабатывает по фронту (одно нажатие — одно переключение), повтор при
  удержании игнорируется.
- R работает только пока фоновая эволюция не запущена.
- Клавиши именуются физически: регистр не важен, раскладка не влияет (SDL
  читает сканкоды). Поддерживаются буквы, цифры и имена
  `space, return, esc, tab, left, right, up, down`.
